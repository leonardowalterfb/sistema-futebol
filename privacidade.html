Política de Privacidade

Este sistema coleta dados como nome, telefon, CPF e data de nascimento para gerenciamento de turmas esportivas.

Os dados não são compartilhados com terceiros e são utilizados apenas pelo responsável da turma.

O usuário pode solicitar a exclusão ou alteração dos seus dados a qualquer momento.

Os dados são armazenados de forma segura e protegidos contra acessos não autorizados.

Ao utilizar o sistema, o usuário concorda com esta política.
